Understanding AWS Free Tier and Docker Deployment
AWS Free Tier Clarification
750 hours is PER SERVICE TYPE, not per container:

EC2: 750 hours of t2.micro instances (can run multiple containers on ONE instance)
RDS: 750 hours of db.t3.micro/db.t4g.micro instances
Total: You get BOTH 750 hours of EC2 AND 750 hours of RDS
What Happens When You Run Docker Compose on EC2
When you run docker compose up on an EC2 instance:

Creates 2 containers on the SAME EC2 instance
NOT 2 separate EC2 instances
Uses only 1 EC2 instance worth of your 750 hours
Recommended Approach for Free Tier Optimization
Option 1: Both Containers on EC2 (Current Setup)
Cost: Uses only EC2 free tier hours

Option 2: Split Architecture (Recommended)
Cost: Uses both EC2 AND RDS free tier hours (better resource allocation)
